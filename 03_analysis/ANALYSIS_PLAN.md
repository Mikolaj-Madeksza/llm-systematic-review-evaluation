# Statistical analysis plan

Operational analysis plan for the finalized reference (`02_data/reference/`, reference version final_v12) and current results (`03_analysis/results/current/`). The plan was developed after review of source material and original outputs and is not prospectively registered. The main randomized verification-quality outcome is net change in error rate.

## Questions and units

Compare GPT and Claude original-output field accuracy separately for extraction and ROBUST-RCT; assess whether original uncertainty flags identify errors; estimate the effect of showing those flags on active human verification time. The experiment contains 96 report IDs, two model outputs per report/task, and 384 verification sessions. Returned sheets are corrections to model outputs, not independent human extractions. No inter-reviewer kappa or four-independent-rater analysis is appropriate.

Fields are nested within report and model. All model comparisons are paired within report. The primary sampling cluster is the report ID, matching assignment and review. A sensitivity analysis will combine the confirmed Mousa 2017/Naderpoor 2018 companion pair into one resampling cluster. Other IDs are not certified independent clinical trials. Findings describe these saved model runs, reports, prompts and two reviewers, rather than all possible runs or all reviewers.

## Reference and eligible comparison sets

MM checked discrepancies against the source PDFs using the predefined extraction rules and ROBUST-RCT criteria, blinded to model and reviewer identities. Seven uncertain cases were discussed with AA and resolved by consensus. MM also assessed the RoB supporting explanations under the same blinding. Adjudication records contain assessment IDs; model identities are linked separately for analysis.

Use the study-specific outcome lists, named outcome variants and arm restrictions in `02_data/inputs/metadata_reference_standard.xlsx` to define the extraction scope. Targets outside this scope are excluded from both primary and augmented denominators, whether or not a model emitted a corresponding row. Source-measure names resolve outcome-code aliases. Original reviewed row and field burdens remain the workloads actually presented to reviewers.

Use adjudicable category A/B fields within `primary_eligible` for the main analysis: main-report evidence only, excluding graph-only and identified supplement-dependent targets. Use adjudicable category A/B fields within `augmented_eligible` in a separately labelled sensitivity analysis. Supplement access at model generation is not fully reconstructable; augmented results must not be described as a fair same-input performance estimate. Preserve all investigator decisions, including Moreira-Lucas mean 50.6 without CIs and Trummer's unknown paired-cohort HbA1c sample sizes. Source inconsistencies are retained as extraction targets, not corrected into clinically plausible numbers.

Both models use the same target-field universe. All-blank structural fields are excluded. The main denominator is the active union across reference and original/returned streams; it includes correct abstention when a field is legitimately blank but another stream asserts a value. Missing model rows remain represented and score E1 on required nonblank targets. An absent field whose reference is genuinely unreported receives no omission penalty, including within an omitted row. This denominator is partly output-dependent: therefore also report reference-nonblank accuracy/completeness and a separate audit of unsupported assertions against reference blanks. Do not imply that a missing row's blank CI proves deliberate abstention. Extra pooled/nonrandomized records are reported as unnecessary records separately, outside the canonical field denominator.

No general numerical tolerance, scale conversion or outcome-unit conversion is applied. Accept the explicitly reviewed semantic equivalences implemented in `value_equivalence.py`: unit typography and case, metadata whitespace/case and label order, restricted study-specific timepoint precision, exact daily-dose calculation variants, and the enumerated percentage-rounding pairs (6.7/6.67, 22.2/22.22, 14.4/14.44). Do not equate substantively different weeks, actual doses with sentinel codes, SD with SE/CI, ITT with PP, or baseline with change/follow-up. Source-locator text is not accuracy-scored. Literal differences are audit diagnostics, not a strict-literal accuracy sensitivity. Original raw text governs original scoring; preserve the two documented source/workbook serialization differences.

When multiple reports were supplied for one extraction task, a source-supported representation from either report satisfies the requested outcome and arm; separate rows from every report are not required. Alternative values must retain coherent statistic, dispersion, value-type and time-point labels. This applies to Al-Mulhim 2015 and AlSheikh 2019. Unit typography equivalence also applies within accepted alternatives. Mostafai group C is outside the requested scope; the shared yogurt vehicle in eligible groups A/B permits either cointervention encoding. Niroomand arm-specific counts and derived attrition fields are category C because the abstract and body disagree; the reported overall total remains usable. The source-supported endpoint alternatives for Nimitphong are accepted as complete, consistently labelled rows. These rules apply identically to original and returned outputs.

Reference fields have adjudication category A (verifiable), B (defensible rule-based/source-reviewed reference) or C (unverifiable). A/B enter binary scoring when otherwise eligible; C remains retained but has null correctness/error/type and is excluded from accuracy, verification-quality and error-triage confusion matrices. Do not exclude an entire report when some fields are C. Unestablished references are not adjudicated blanks; genuine nonapplicability and source-unreported values retain their separate rules. No missing reference is assigned zero or an arbitrary judgment. Complete RoB item composites require adjudicable judgment components, though other known item fields remain scorable.

## Primary performance outcomes

1. **Extraction field accuracy:** correct eligible `numeric` and `metadata` fields divided by all such eligible fields. This field-weighted proportion is primary, consistent with the master protocol. Also show numeric and metadata domains separately and equal-weight report-level averages to expose the influence of large tables and repeated metadata.
2. **RoB field accuracy:** pool eligible step1 and step2 judgment fields with one semantic-rationale field per model-item. The rationale field is correct only if all material support claims are supported. Do not count the three alternative support-text storage columns as three separate rationales. Structural blank step1 for item6 is excluded. Report judgment and rationale domains separately, so their weighting remains visible. Group attrition counts and once-per-report outcome scope are separate secondary domains, not silently added to the primary RoB denominator.

For each task, report each model's accuracy and the paired absolute difference (GPT minus Claude), in percentage points. Use 10,000 report-cluster bootstrap replicates, seed 20261007, resampling reports with replacement and retaining both models, all fields, returned values and flags together. Recompute ratios using cluster multiplicities; do not deduplicate repeated bootstrap IDs. Use 2.5th and 97.5th percentiles for 95% intervals. The same resamples yield model-specific and paired-difference intervals. No field-independent binomial confidence interval or field-level chi-square test is permitted. These are estimation analyses; no primary significance threshold or confirmatory p-values will be used, and interval exclusion of zero will not be treated as proof of model superiority across all settings.

Secondary RoB item accuracy requires the judgment pair and rationale to be correct (`original_item_composite_error == 0`), with item6 counts reported separately. Show item-level patterns. Report E1/E2 distributions and unflagged E2 counts/rates with explicit denominators. Extra-record counts remain separate. These secondary/subgroup intervals are exploratory and not multiplicity-adjusted; avoid selective significance claims.

## Category C descriptive assessment

Report C separately from binary accuracy. For each unknown value distinguish a plausible but unverified estimate, no estimate, and demonstrable evidence/arithmetic violations. A value satisfying known constraints is not thereby correct. Assess whether the original uncertainty flag addresses the actual unresolved issue, rather than just containing any U1/U2. Summarize uncertainty handling once per report × model × original source row × domain; item-6 unknown counts and rating share one flag. A missing relevant flag represents missed uncertainty, not a numerical E2. For jointly inconsistent arm counts against a known total, report at least one established violation without labelling every component wrong. Keep demonstrable errors in this descriptive track rather than treating the unknown value as a binary reference standard.

## Human verification outcomes

Use the same reference fields and denominator for original and returned values. Estimate errors corrected, errors remaining, and correct values changed to incorrect, separately by task/model and explicit uncertainty flag visibility. These are assisted-review outcomes, not standalone human accuracy. Rationale text was unchanged across all 1,152 original/returned item records: reuse its semantic code, while independently scoring changed judgment fields. An unchanged rationale is not evidence that a reviewer endorsed every claim.

## Uncertainty-flag performance (error triage)

Only original flags are predictors. Treat any nonempty domain U1/U2 flag as positive; actual original error is the target. Do not use adjudicator flags as model predictions. These are binary uncertainty-flag performance / error-triage analyses, not statistical probability calibration. No Brier score or probability-calibration curve is appropriate.

**Primary extraction unit:** report × model × emitted source row × domain (`metadata` or `numeric`). Collapse relevant primary-eligible fields within that domain to one binary outcome: any original error. Each domain-specific flag is counted once, regardless of how many fields inherit it. A domain with no eligible active fields does not enter the denominator. Report metadata and numeric domains separately; their combined result counts one prediction per row-domain, not one per whole row.

**Primary RoB unit:** report × model × item, with outcome equal to any judgment-pair or rationale error (`original_item_composite_error`). Each item flag is counted once. Group counts and outcome-scope fields are not added to this composite. Secondary analyses report extraction field-weighted performance (downstream error burden), RoB judgment-field performance, and item6 count-field performance; outcome scope is excluded because its item1 flag is only a proxy.

The primary analysis is conditional on emitted rows. Missing model rows have no observed flag, so they are excluded here but remain E1 omissions in accuracy. Add an **all-target safety sensitivity**: for each required primary-eligible target row absent from a model, create one synthetic unflagged error/FN per domain with at least one nonblank reference field. Do not create synthetic predictions for entirely structural/blank domains, excluded graph/supplement targets, or duplicate the omitted row once per field. Present the added FN counts and their effect on NPV/sensitivity alongside the emitted-row analysis. The same rule applies to a missing required RoB item if one exists. Label these as policy-based safety assignments, not observed model confidence. This sensitivity is not a measure of surplus-row detection.

For each model and domain report TP, FP, TN, FN; sensitivity TP/(TP+FN), specificity TN/(TN+FP), PPV TP/(TP+FP), NPV TN/(TN+FN), flagged/unflagged error rates, flag prevalence, and certain-but-wrong prevalence FN/all eligible units. Distinguish that prevalence from the unflagged error rate FN/(TN+FN). Over-flagging is FP/(TP+FP), accompanied by FP/all. Add **absolute error enrichment** = flagged error rate minus unflagged error rate (percentage points), and **relative error enrichment** = flagged error rate divided by unflagged error rate. Relative enrichment has reference value 1; it does not establish causal benefit of flagging.

Undefined ratios are NA with their zero denominator, never zero. A positive flagged error rate divided by zero unflagged error rate is infinite, not a finite estimate; no continuity correction is applied. Bootstrap all metrics and enrichment contrasts by report using the same 10,000 draws as accuracy. Report valid finite replicate counts; suppress an interval when fewer than 95% of replicates are finite. U1/U2-specific results are exploratory, with a subtype-positive flag compared against all other emitted units. Repeat primary performance with known companion-report clustering as sensitivity.

### Randomized visibility contrasts for verification quality

**Primary verification-quality contrast:** for extraction and RoB separately, pooling models, estimate the visible-minus-hidden difference in net verification change:

`(returned error rate − original error rate)_visible − (returned error rate − original error rate)_hidden`.

Within each visibility arm, use identical eligible fields and denominators for original and returned rates; positive values mean less favorable net verification with visible structured flags. Calculate all four rates and the difference in differences jointly in each of the 10,000 report-cluster bootstrap replicates (seed 20261007); use percentile 95% CIs. This is the observed randomized assignment, not a permutation test. The net-change estimand was chosen after initial results had been examined and must not be described as prospectively specified.

As **secondary verification-quality contrasts**, estimate (1) residual returned error rate, (2) proportion of original errors corrected, and (3) proportion of originally correct fields made incorrect. Use the same primary field universe as accuracy, separately for extraction and RoB, pooling models for the main randomized contrast. Define each arm’s rate from its pooled numerator and denominator: returned errors/all eligible fields; original-error-to-correct transitions/original errors; original-correct-to-error transitions/original correct fields. Include the semantic rationale field in RoB and show judgment-only and item-composite results separately as secondary checks.

Obtain 95% report-clustered percentile bootstrap CIs for arm-specific rates and their visible-minus-hidden differences, keeping all sessions/fields within resampled reports. Report counts and denominator composition by visibility; the field-weighted estimand can weight large reports more heavily. Also report model-stratified contrasts as exploratory and known-companion-cluster sensitivity. Do not condition the primary contrast on post-review error counts or remove unchanged fields.

The treatment is **explicit uncertainty flag visibility**: dedicated structured uncertainty fields visible versus hidden. Natural-language epistemic wording remains visible in retained RoB rationales in both arms. Thus the estimand does not compare all uncertainty information with no uncertainty information. These quality contrasts support a safety-efficiency assessment, but a nonsignificant quality difference is not evidence of noninferiority; no noninferiority margin was prespecified.

## Verification-time analysis

Use one row per session in `sessions.csv`. Analyze extraction and RoB separately (192 sessions each). Retain all positive recorded times; no trimming or winsorization based on results. Do not join times onto fields and treat the repeated values as observations. Report unadjusted distributions by visibility and task, then the adjusted visibility contrast.

Primary adjusted model is ordinary least squares for log(active seconds), with report fixed effects, model, reviewer, explicit uncertainty flag visibility, and centered review order. Extraction additionally includes centered log(original row burden). For RoB, omit row burden: it is collinear with report fixed effects in this design. A pre-outcome design-matrix check confirmed estimability of the remaining terms. There are only two reviewers; use reviewer fixed effects, not an estimated reviewer population variance.

Use CR2 report-cluster robust standard errors with Satterthwaite degrees of freedom (R `clubSandwich` implementation) for the visibility coefficient. Exponentiate coefficient and interval to report visible/hidden geometric-mean time ratio, with `(ratio-1)*100` as percentage change. The primary adjustment uses burden presented to the reviewer, not final reference-standard field counts or the number of errors ultimately found. Treat model/reviewer/order coefficients as adjustments, not independent primary discoveries. Recheck matrix rank before fitting; stop and document any unanticipated nonestimability rather than silently drop visibility or another required term.

Sensitivity analyses: (a) omit extraction burden; (b) replace row burden with original nonblank field burden, checking rank and omitting it only if absorbed by report effects; (c) raw-seconds model with the same design and CR2 to estimate an adjusted absolute time difference; (d) known companion-pair clustering; (e) exploratory model-by-visibility interaction. No automated outlier deletion. Any data correction requires a source-backed audit entry and rebuild.

Describe seconds per originally presented nonblank field as a session-level ratio using `original_nonblank_field_burden_excluding_uncertainty`, explicitly identifying the denominator and unequal cognitive effort per cell. This ratio is secondary; do not count each field as a separate timed observation. Review order models an approximate linear learning/fatigue trend, not elapsed calendar time.

## Missingness, reproducibility and reporting limits

All 384 recorded sessions have positive time values. No missing-time imputation is planned. Intentional reference nulls mean unreported/uncertain, never zero. All 1,152 semantic records are coded; no unresolved semantic item is silently counted correct. The three support columns represent one narrative per item. Score E2 only for materially false source claims, fabricated support, demonstrably wrong counting/decision rules or wrong-source attribution; E1 for absent/materially incomplete support. Do not label defensible qualified inference, alternate appropriate ratings or wording differences as narrative errors. A wrong judgment does not itself establish a wrong rationale; the unchanged original/returned narrative receives the same semantic decision. Use the rationale rubric and recorded reasons as the auditable basis of those labels.

For reproducibility, verify reference/input/output hashes, dataset validations and design rank. Save software/package versions, random seed, exact input hashes, analysis script and machine-readable results. Distinguish the finalized operational choices from prospectively prespecified methods.

Reporting limitations include output-dependent union denominators, incomplete supplement-input provenance, one run per report/model/task, unchanged reviewer rationale text, and known companion reports. The supplemental agreement sample was selected after source review. Natural-language epistemic wording remained visible in RoB rationales even when explicit uncertainty fields were hidden.

Exact generation dates and resolved prompt-error rerun counts are reporting metadata still to recover if available; their absence does not prevent these analyses and must be reported as unavailable rather than inferred from filesystem timestamps. This dataset is prepared for the methodological LLM evaluation, not direct clinical meta-analysis.
